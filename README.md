# SEIAJUDA-app
SEI Guia é uma aplicação desktop desenvolvida em Python e PySide6 para capacitação de servidores públicos no uso do Sistema Eletrônico de Informações (SEI). Oferece cursos organizados por módulos, conteúdos explicativos, acompanhamento de aprendizagem e avaliações, promovendo maior autonomia, segurança e padronização na utilização do sistema.
